ATIVIDADE 05

Programação de um LED RGB

Descubra como misturar cores usando os pinos digitais PWM do Arduino para controlar um LED RGB e criar diversos efeitos visuais.

Instruções Práticas

  1. Abra o seu ambiente de simulação no Tinkercad.
  2. Adicione uma placa Arduino Uno, uma Protoboard, um LED RGB e três resistores de 220Ω.
  3. Identifique o pino mais longo do LED RGB (Catodo Comum) e conecte ao GND do Arduino.
  4. Conecte o pino Vermelho (Red) através de um resistor ao pino digital 11 (PWM) do Arduino.
  5. Conecte o pino Verde (Green) através de um resistor ao pino digital 10 (PWM) do Arduino.
  6. Conecte o pino Azul (Blue) através de um resistor ao pino digital 9 (PWM) do Arduino.
  7. Insira o código de programação utilizando uma função personalizada e comandos analogWrite() para definir a cor desejada.
  8. Inicie a simulação e observe o LED criar diferentes cores pela mistura de luzes!

Código de Exemplo

// Código C++ - Controle de LED RGB

int pinoR = 11; // Pino do LED Vermelho (Red)
int pinoG = 10; // Pino do LED Verde (Green)
int pinoB = 9;  // Pino do LED Azul (Blue)

void setup()
{
    pinMode(pinoR, OUTPUT);
    pinMode(pinoG, OUTPUT);
    pinMode(pinoB, OUTPUT);
}

// Função para simplificar a mudança de cores
void definirCor(int r, int g, int b) {
    analogWrite(pinoR, r);
    analogWrite(pinoG, g);
    analogWrite(pinoB, b);
}

void loop()
{
    definirCor(255, 0, 0);     // Vermelho
    delay(1000);
    definirCor(0, 255, 0);     // Verde
    delay(1000);
    definirCor(0, 0, 255);     // Azul
    delay(1000);
    definirCor(255, 255, 0);   // Amarelo
    delay(1000);
    definirCor(255, 255, 255); // Branco
    delay(1000);
}

LED RGB

São 3 pequenos LEDs (Red, Green, Blue) no mesmo encapsulamento.

PWM

Permite variar a intensidade de cada cor de 0 a 255 independentemente.

Catodo Comum

O pino mais longo, que deve ser conectado ao GND (Terra) do circuito.

Síntese Aditiva

Mistura de luzes: ligar todas as 3 cores na potência máxima cria a luz branca.
