ATIVIDADE 02

Controlando com Botão

Introduza interatividade ao seu projeto. Utilize estruturas de condição (IF/ELSE) para ler o estado de um botão.

Instruções Práticas

  1. Abra o seu ambiente de simulação no Tinkercad.
  2. Adicione uma placa Arduino, uma Protoboard, um Pushbutton (Botão), um LED e resistores.
  3. Conecte o LED através de um resistor ao pino digital 12 do Arduino.
  4. Conecte um terminal do botão aos 5V e o outro terminal ao pino digital 4 do Arduino.
  5. Adicione um resistor (pull-down) conectando o pino 4 ao GND (Terra) para evitar ruídos.
  6. Utilize a estrutura de condição if / else no código para ler o estado do botão.
  7. Programe o LED para acender apenas quando o botão estiver pressionado.

Código de Exemplo

// Código C++ - Controle de LED com Botão

int pinoBotao = 4; // Define o pino do botão
int pinoLed = 12;  // Define o pino do LED
int estadoBotao = 0; // Variável para guardar a leitura do botão

void setup()
{
    // Configura o botão como ENTRADA de sinal
    pinMode(pinoBotao, INPUT);
    // Configura o LED como SAÍDA de energia
    pinMode(pinoLed, OUTPUT);
}

void loop()
{
    // Lê o estado atual do botão (HIGH ou LOW) e guarda na variável
    estadoBotao = digitalRead(pinoBotao);

    // Estrutura de condição: SE o botão estiver pressionado
    if (estadoBotao == HIGH) {
        digitalWrite(pinoLed, HIGH); // Acende o LED
    } 
    // SENÃO (se o botão não estiver pressionado)
    else {
        digitalWrite(pinoLed, LOW);  // Apaga o LED
    }
}

Tabela de Lógica Condicional

Ação Física no Botão Sinal Lido (digitalRead) Condição Atendida Ação Executada no LED
Pressionado (Fechado) HIGH (5V) IF (Se) Acende o LED
Solto (Aberto) LOW (0V) ELSE (Senão) Apaga o LED
INPUT (Entrada)

Usado para dizer ao Arduino que ele deve "escutar" o sinal que vem de fora, como o clique de um botão.

Variáveis

São como "caixas" na memória do Arduino usadas para guardar valores. No código, guardamos se o botão está apertado ou solto.

IF / ELSE

Lógica de decisão. O Arduino analisa uma pergunta (Ex: Botão == HIGH?). Se for verdade faz o IF, caso contrário faz o ELSE.

Resistor Pull-Down

Garante que quando o botão estiver solto, o Arduino leia perfeitamente LOW (0V), evitando "ruídos" na leitura.

Transformando a lógica de programação em algo visual, interativo e divertido através da robótica educacional.
