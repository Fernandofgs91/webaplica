ATIVIDADE 03

Fazer um Semáforo

Domine sequências temporizadas e a lógica de atrasos (delay) para alternar múltiplos estados dos LEDs vermelho, verde e amarelo.

Instruções Práticas

  1. Abra o seu ambiente de simulação no Tinkercad.
  2. Adicione uma placa Arduino, uma Protoboard, três resistores de 220Ω e três LEDs nas cores vermelho, amarelo e verde.
  3. Conecte o cátodo (perna negativa) de cada LED na linha de GND da protoboard, ligando-a ao pino GND do Arduino.
  4. Conecte o ânodo (perna positiva) do LED vermelho através de um resistor ao pino digital 13 do Arduino.
  5. Conecte o ânodo do LED verde através de um resistor ao pino digital 12 do Arduino.
  6. Conecte o ânodo do LED amarelo através de um resistor ao pino digital 11 do Arduino.
  7. Insira o código de programação utilizando comandos de acendimento e temporizadores (delay) para alternar os estados do semáforo.
  8. Inicie a simulação para testar a sequência de luzes do semáforo!

Código de Exemplo

// Código C++ - Controle de Semáforo

int ledVermelho = 13;
int ledVerde = 12;
int ledAmarelo = 11;

void setup()
{
    // Configura todos os LEDs como SAÍDA
    pinMode(ledVermelho, OUTPUT);
    pinMode(ledVerde, OUTPUT);
    pinMode(ledAmarelo, OUTPUT);
}

void loop()
{
    // FASE 1: Sinal Verde (Siga)
    digitalWrite(ledVerde, HIGH);
    digitalWrite(ledAmarelo, LOW);
    digitalWrite(ledVermelho, LOW);
    delay(5000); // Fica verde por 5 segundos

    // FASE 2: Sinal Amarelo (Atenção)
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledAmarelo, HIGH);
    digitalWrite(ledVermelho, LOW);
    delay(2000); // Fica amarelo por 2 segundos

    // FASE 3: Sinal Vermelho (Pare)
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledAmarelo, LOW);
    digitalWrite(ledVermelho, HIGH);
    delay(5000); // Fica vermelho por 5 segundos
}

Tabela de Temporização e Estados

Fase do Semáforo LED Verde (Pino 12) LED Amarelo (Pino 11) LED Vermelho (Pino 13) Tempo (Delay)
Siga (Verde) HIGH (Ligado) LOW LOW 5000ms (5s)
Atenção (Amarelo) LOW HIGH (Ligado) LOW 2000ms (2s)
Pare (Vermelho) LOW LOW HIGH (Ligado) 5000ms (5s)
Sequenciamento

O Arduino lê o código de cima para baixo. A ordem em que você escreve os comandos é exatamente a ordem em que as luzes vão acender.

Função Delay()

Pausa o programa por um tempo especificado em milissegundos (1 segundo = 1000 milissegundos).

Limpeza de Estados

É essencial garantir que as outras luzes recebam o comando LOW (desligar) quando uma nova luz acender.

Loop Infinito

Após a fase vermelha terminar, o código chega ao fim do loop() e recomeça instantaneamente pela fase verde.
