ATIVIDADE 04

Controlando a Luz do LED com Potenciômetro

Domine a leitura de sinais analógicos e o controle de intensidade luminosa (PWM) para variar o brilho de um LED em tempo real.

Instruções Práticas

  1. Abra o seu ambiente de simulação no Tinkercad.
  2. Adicione uma placa Arduino Uno, uma Protoboard, um potenciômetro de 10kΩ, um resistor de 220Ω e um LED (qualquer cor).
  3. Conecte o pino 1 do potenciômetro ao 5V do Arduino.
  4. Conecte o pino 3 do potenciômetro ao GND do Arduino.
  5. Conecte o pino 2 (central) do potenciômetro ao pino analógico A0 do Arduino.
  6. Conecte o catodo (perna negativa) do LED ao GND do Arduino.
  7. Conecte o anodo (perna positiva) do LED através do resistor de 220Ω ao pino digital 9 (PWM) do Arduino.
  8. Insira o código de programação utilizando os comandos analogRead(), map() e analogWrite() para controlar o brilho do LED.
  9. Inicie a simulação e gire o potenciômetro para ver o brilho do LED variar em tempo real!

Código de Exemplo

// Código C++ - Controle de LED com Potenciômetro

int valorPot = 0;  // Variável para armazenar a leitura do potenciômetro

void setup()
{
    pinMode(A0, INPUT);   // Configura pino A0 como entrada analógica
    pinMode(9, OUTPUT);   // Configura pino 9 como saída PWM
}

void loop()
{
    valorPot = analogRead(A0);                      // Lê o valor do potenciômetro (0-1023)
    analogWrite(9, map(valorPot, 0, 1023, 0, 255)); // Mapeia e escreve no LED
    delay(10);                                      // Pequena pausa para estabilização
}
