Instruções Práticas

  1. Abra o seu ambiente de simulação no Tinkercad.
  2. Arraste uma placa Arduino Uno para a área de trabalho.
  3. Conecte um LED e um Resistor (recomendado 220Ω ou 330Ω).
  4. Ligue o terminal positivo do LED (Anodo) ao pino digital 11 do Arduino.
  5. Copie o código base disponível na videoaula e cole na aba de código do simulador.
  6. Clique em "Iniciar Simulação" e veja o LED piscar!

Código de Exemplo

// Código C++ - Piscar um LED (Blink)

int pinoLed = 11; // Define o pino onde o LED está conectado

void setup()
{
    // Configura o pino do LED como uma SAÍDA de energia
    pinMode(pinoLed, OUTPUT);
}

void loop()
{
    digitalWrite(pinoLed, HIGH); // Liga o LED (nível de energia ALTO - 5V)
    delay(1000);                 // Espera por 1000 milissegundos (1 segundo)
    
    digitalWrite(pinoLed, LOW);  // Desliga o LED (nível de energia BAIXO - 0V)
    delay(1000);                 // Espera por mais 1 segundo antes de repetir
}

Tabela de Estados (Sinais Digitais)

Comando Arduino Sinal Lógico Tensão (V) Estado do LED
digitalWrite(pino, HIGH) 1 (Verdadeiro) 5V Aceso
digitalWrite(pino, LOW) 0 (Falso) 0V Apagado
Polaridade do LED

O LED tem lado certo! O Anodo (perna maior) é o positivo e o Catodo (perna menor) é o negativo.

Resistor

Usado para limitar a corrente elétrica. Sem ele, o LED pode receber muita energia e queimar.

Pinos Digitais

Funcionam apenas com dois estados: ligado (HIGH) ou desligado (LOW).

Estrutura do Código

O setup() roda apenas uma vez no início, enquanto o loop() repete os comandos para sempre.

Transformando a lógica de programação em algo visual, interativo e divertido através da robótica educacional.
